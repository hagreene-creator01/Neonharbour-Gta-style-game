# Neonharbour-Gta-style-game
Neon Harbour: a GTA-inspired 3D open-city crime sandbox that runs in your browser. Steal cars, take on 8 jobs, shake the cops, and explore a neon-lit city at dusk. Built with Three.js in a single HTML file. Coded using claude


Neon Harbour is a playable open-city prototype set in a neon-lit city at dusk. Walk or drive around, steal cars, dodge traffic, and run jobs across town, from pizza deliveries and street races to bank jobs and police chases. Cause too much trouble and the cops come after you.

Features: 3D city with day-to-dusk lighting, AI traffic and pedestrians, a wanted system with police pursuits, 8 jobs, a minimap and full map with waypoints, save slots and save files, rebindable controls, and a cinematic startup intro.

Play: open Neonharbour.html in a modern browser (needs internet the first time to load three.js). Controls: WASD to move or drive, Shift to sprint, F to enter or exit a car, J to shoot, Esc for the menu.

A fan-made prototype, not affiliated with or endorsed by Rockstar Games

Features save file and auto save but only saves on the browser that you use, will not work if you change browser but there are manual save slots and save code you can use
